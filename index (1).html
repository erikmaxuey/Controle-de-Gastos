Como usar

  • Toque em um gasto para editar ou apagar.
  • Segure um gasto e arraste para reordenar.
  • Deslize para o lado para mudar de mês.
  • Use “+ Adicionar” no fim de cada lista para lançar um gasto.
  • O app lembra o último mês e a última aba que você usou.
  • Os dados ficam salvos só neste aparelho. Faça backup de vez em quando, pelo menu ⋮.
